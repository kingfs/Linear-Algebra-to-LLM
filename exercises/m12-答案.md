# M12 习题答案

> 对应 [m12-习题](m12-习题.md)。

## A 概念题

1. 自由索引出现在输出中，保留为结果轴；求和索引只出现在输入中，被求和消去。
2. `"ii->"` 中 $i$ 同时作为行/列索引，只取对角线元素再求和；`"ij->"` 对所有 $i,j$ 求和。
3. 随机矩阵的最大奇异值约为 $\sigma(\sqrt m+\sqrt n)$；方差 $1/n$ 的方阵约为 2，不是 1。
4. 空间（秩-零化度）、映射（$A\mathbf{x}=\mathbf{b}$）、方程（正规方程）、谱（$A=U\Sigma V^\top$）、计算（条件数）。
5. 对任意 $m\times n$ 矩阵存在，$U,V$ 正交，且秩/范数/伪逆/最小二乘都可由它读出。
6. Prefill 计算受限；decode 带宽受限。

## B 计算题

1. `"bik,bkj->bij"`；`"ij->ji"`；`"i,j->ij"`；`"ij->i"`；`"i,i->"`。
2. $AB=\begin{bmatrix}2&1\\4&3\end{bmatrix}$。
3. 方差 1：约 $2\sqrt{1000}\approx63$；方差 $1/n$：约 2。
4. 特征值 2,1；奇异值 2,1；条件数 2；秩 2。
5. `"bhid,bhjd->bhij"`，形状 `[B,H,T,T]`。
6. $2000/14\approx143$ tokens/s。

## C 大模型题

1. `O = einsum("bhij,bhjd->bhid", A, V)` → `[B,H,T,d]`；`Y = einsum("bhtd,de->bhte", O.transpose(0,2,1,3).reshape(B,T,D), Wo)` → `[B,T,D]`。
2. 显存减半、带宽需求减半；损失精度（尤其长序列误差累积），可能需要 per-channel/group 量化或保留敏感层。
3. fan-in 控制前向方差，fan-out 控制反向方差；它们影响权重矩阵的谱尺度，目标是让每层放大倍率接近 1。
4. 理论收益：显存/带宽约「秩比 × 位宽比」；风险：低秩分解改变权重分布，量化误差在低秩基上放大；需联合校准与端到端评估。

## D 开放题

1. 开放；示例：LoRA 的 $BA$ 对应秩约束；attention 的 $QK^\top$ 对应低秩分数矩阵。
2. 指标：显存、吞吐、TTFT/TPOT、长上下文任务准确率/困惑度；baseline：fp16 KV；消融：int8 vs int4、per-tensor vs per-group、不同序列长度。
