# M12 习题：进阶与全景

> 对应模块：[M12 进阶](../12-进阶/README.md)

## A 概念题

1. einsum 中「自由索引」与「求和索引」有什么区别？
2. 为什么 `"ii->"` 是迹，而 `"ij->"` 是所有元素求和？
3. 随机矩阵的谱范数为什么不是 1？方差 $1/n$ 时是多少？
4. 五条主线分别是什么？各举一个核心公式。
5. 为什么 SVD 被称为「任意矩阵的终极分解」？
6. 推理的 prefill 与 decode 阶段，瓶颈分别是什么？

## B 计算题

1. 写出以下运算的 einsum：批量矩阵乘、转置、外积、行和、内积。
2. $A=\begin{bmatrix}1&2\\3&4\end{bmatrix}$，$B=\begin{bmatrix}0&1\\1&0\end{bmatrix}$，用 `"ij,jk->ik"` 手算 $AB$。
3. $n=1000$ 的高斯矩阵（方差 1），谱范数量级是多少？方差 $1/n$ 呢？
4. $A=\begin{bmatrix}2&0\\0&1\end{bmatrix}$，求特征值、奇异值、条件数、秩。
5. 注意力 $Q,K\in\mathbb{R}^{B\times H\times T\times d}$，写出 $QK^\top$ 的 einsum 与输出形状。
6. 7B 模型 fp16 权重 14 GB，HBM 带宽 2 TB/s，估算 decode 的 tokens/s 上限。

## C 大模型题

1. 用 einsum 写出「多头 attention 输出投影」的完整两步，并标注形状。
2. 若把 KV Cache 量化到 int8，显存和带宽各有什么变化？可能损失什么？
3. 为什么随机初始化时要用 fan-in/fan-out？与谱范数有什么关系？
4. 一个「低秩 + 量化」的联合压缩方案，理论收益如何估算？有哪些耦合风险？

## D 开放题

1. 选一个你学过的概念，说明它在你读过的某篇大模型论文/博客中如何出现。
2. 设计一个 4 周项目：验证「KV Cache 量化对长上下文质量的影响」，写出指标、baseline、消融。
