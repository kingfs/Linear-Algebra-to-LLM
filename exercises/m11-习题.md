# M11 习题：大模型中的线性代数

> 对应模块：[M11 大模型专题](../11-大模型专题/README.md)
> 先独立完成，再对 [答案](m11-答案.md)。计算题请写清形状与单位。

## A 概念题

1. 为什么 embedding 查表等价于 one-hot 向量乘矩阵 $E^\top$？
2. 为什么多层线性层（无非线性）叠加等价于一层？这对 Transformer 的设计意味着什么？
3. attention 为什么要把 Q、K、V 分开投影？如果令 $W_Q=W_K=W_V$ 会失去什么？
4. 为什么 attention 要除以 $\sqrt{d_k}$？从方差角度解释。
5. 因果 mask 为什么必须在 softmax 之前加 $-\infty$？
6. LayerNorm 与 RMSNorm 的核心区别是什么？为什么大模型常用 RMSNorm？
7. KV Cache 缓存的是什么？为什么它「省计算但费显存」？
8. LoRA 的低秩约束作用在权重还是更新上？为什么初始化时令 $B=0$？

## B 计算题

1. $V=50000$，$D=1536$，embedding 参数量是多少？fp16 占多少 MiB？
2. $D=2048$，FFN 为 $D\to4D\to D$，求单层 FFN 参数量；$L=24$ 层共多少？
3. $T=512$，$d_k=64$，$QK^\top$ 有多少元素？若 fp16 存储注意力分数矩阵（$H=16$），占多少 MiB？
4. softmax 输入 $(3,1,0)$，求输出；温度 $T=0.5$ 时呢？
5. $B=1,H=32,T=4096,d_k=128$，fp16，单层 KV Cache 多少 MiB？32 层呢？
6. 若用 GQA $H_{kv}=8$，重算第 5 题。
7. $D=4096$，LoRA $r=16$，$\alpha=32$，求单层单矩阵的 LoRA 参数量与缩放因子。
8. 权重范围 $[-0.5,0.5]$，int8 对称量化，求 $s$；$x=0.1$ 的量化值与反量化误差。

## C 大模型题

1. 一个 7B 模型 $D=4096,L=32$，用 $12D^2L$ 估算主体参数；若词表 $V=32000$ 且权重绑定，估算总参数。
2. 生成 $T=2048$ 个 token，比较「无 KV Cache」与「有 KV Cache」的 attention 计算量数量级。
3. 解释为什么 decode 阶段是带宽受限，而 prefill 是计算受限；各举一个优化手段。
4. 为什么 MoE 的显存按总参数算、计算按激活参数算？这对部署意味着什么？
5. 训练出现 loss spike，列出至少三条可能原因与对应排查指标。

## D 开放题

1. 如果 attention 的所有头都学成相同的 $W_Q,W_K,W_V$，多头的意义还在吗？如何检测头冗余？
2. 「LoRA 的低秩假设」在什么任务上可能失效？如何设计实验验证？
3. 量化到 4-bit 后模型「变笨」，可能的原因有哪些？从误差、outlier、校准三个角度分析。
