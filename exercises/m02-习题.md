# M02 习题：向量空间

> 对应模块：[M02 向量空间](../02-向量空间/README.md)
> 先独立完成，再对 [答案](m02-答案.md)。

## A 概念题

1. 子空间必须满足哪三条？为什么「含零」可以从「非空 + 对数乘封闭」推出？
2. 线性无关与「两两不共线」有什么区别？举一个反例。
3. 基的两个条件是什么？只满足其中一个会出什么问题？
4. 叙述秩-零化度定理，并解释每一项的含义。
5. 为什么相似矩阵有相同的特征值、行列式和迹？这些量描述的是矩阵还是线性映射？
6. 正交补 $S^\perp$ 与「补集」有什么区别？
7. 张成回答哪三个问题？分别对应解方程、求秩、做投影中的哪一个？

## B 计算题

1. 判断下列集合是否为 $\mathbb{R}^3$ 的子空间：
   (a) $\{(x,y,z)\mid x=2y\}$；(b) $\{(x,y,z)\mid x+y+z=1\}$；(c) $\{(x,y,z)\mid xy=0\}$；(d) $\{(x,y,z)\mid x=y=z\}$。
2. 判断 $\mathbf{v}_1=(1,2,3)$、$\mathbf{v}_2=(2,3,4)$、$\mathbf{v}_3=(3,5,7)$ 是否线性无关；若相关，写出非平凡关系。
3. 求 $A=\begin{bmatrix}1&2&3\\2&5&7\\1&3&4\end{bmatrix}$ 的秩、列空间维数、零空间维数。
4. 求 $A=\begin{bmatrix}1&2&0\\0&1&1\end{bmatrix}$ 的零空间的一组基。
5. $\mathcal{B}=\{(1,2),(2,3)\}$，求 $\mathbf{v}=(4,7)$ 在 $\mathcal{B}$ 下的坐标。
6. 对 $\mathbf{v}_1=(1,1,0)$、$\mathbf{v}_2=(1,2,0)$、$\mathbf{v}_3=(0,0,1)$ 做 Gram–Schmidt。
7. 设 $A=\begin{bmatrix}2&1\\1&2\end{bmatrix}$，$P=\begin{bmatrix}1&1\\1&-1\end{bmatrix}$，求 $P^{-1}AP$，并验证迹与行列式。

## C 大模型题

1. LoRA 中 $B\in\mathbb{R}^{4096\times16}$、$A\in\mathbb{R}^{16\times4096}$。求 $\Delta W$ 的秩上界和参数量；与全参数更新相比压缩多少倍？
2. 一批 512 个 token 的激活矩阵 $H\in\mathbb{R}^{512\times4096}$。它的秩最大是多少？若 SVD 显示前 32 个奇异值占 99% 能量，说明什么？
3. 若把隐藏空间用正交矩阵 $Q$ 旋转（$\mathbf{h}'=Q\mathbf{h}$），余弦相似度会改变吗？为什么？
4. 为什么「注意力头的输出高度相关」意味着头之间存在冗余？如何用秩来检测？

## D 开放题

1. 「模型激活只在低维子空间」这一假设，有哪些支持证据和反例？如果为真，对推理优化意味着什么？
2. 如果让你设计一种「正交微调」方法，你会如何约束更新矩阵？可能付出什么代价？
