# M00 习题答案

> 对应 [m00-习题](m00-习题.md)。计算题只给关键步骤，等价写法均可。

## A 概念题

1. (a) 线性；(b) 仿射，不是线性（不过原点，$f(0)=2\neq0$）；(c) 非线性（$f(x+y)=(x+y)^2\neq x^2+y^2$）；(d) 线性；(e) 仿射，不是线性。
2. $i$ 只在求和内部起作用，求和完成后结果与 $i$ 无关；换成 $j$ 不改变结果，所以叫哑指标。
3. $(AB)_{ij}=\sum_k a_{ik}b_{kj}$ 是整行乘整列；$a_{ij}b_{ij}$ 是逐元素积（Hadamard）。前者用于线性变换复合，后者用于门控、mask、逐元素缩放。
4. 阶（rank/ndim）是轴的个数；矩阵的秩是列空间的维数。二者英文都叫 rank，但含义不同。

## B 计算题

1. 先固定 $i$：$i=1$ 时 $(3+5)=8$；$i=2$ 时 $(4+6)=10$；$i=3$ 时 $(5+7)=12$；总和 $30$。
2. $AB=\begin{bmatrix}2&1\\4&3\end{bmatrix}$，$BA=\begin{bmatrix}3&4\\1&2\end{bmatrix}$，不相等。
3. (a) 3 个轴，$4\times6\times2=48$ 个元素；(b) `[4, 2]`；(c) `[4, 6]`；(d) 不能，$3\times8\times2=48$ 元素数相同，实际上**可以** reshape（元素数守恒），但轴的含义会改变，需确认语义。
4. $12\times768^2\times12=84{,}934{,}656$；embedding $50257\times768=38{,}597{,}376$；合计约 123.5M，与 124M 吻合（差异来自位置 embedding、LayerNorm 等）。

## C 大模型题

1. 例如：
   `[B,T,D]` → `[B,T,D]`（QKV 投影）→ `[B,T,H,d_k]`（reshape）→ `[B,H,T,d_k]`（transpose）→ `[B,H,T,T]`（$QK^\top$）→ `[B,H,T,T]`（softmax）→ `[B,H,T,d_k]`（$PV$）→ `[B,T,D]`（合头）→ `[B,T,D]`（输出投影）。其中 $d_k=D/H=2$。
2. $\operatorname{softmax}(\mathbf{z}/T)_i=\frac{e^{z_i/T}}{\sum_j e^{z_j/T}}$。$T\to0$：趋向 one-hot（最大项为 1）；$T\to\infty$：趋向均匀分布。
3. 元素数 $1\times32\times4096\times128=16{,}777{,}216$；K、V 共 2 份，fp16 每元素 2 字节：$2\times16777216\times2=67{,}108{,}864$ 字节 $\approx64$ MiB。

## D 开放题

1. 原因：轴顺序约定多（`[B,T,D]` vs `[B,D,T]`）、reshape/transpose 组合易错、广播静默扩展、文档省略形状。建议：每步打印或注释形状；写断言 `assert x.shape == (...)`；用小尺寸单测验证轴语义。
2. 例如「矩阵是一台自动售货机：投进一个向量，按固定比例组合出另一个向量」。边界：矩阵只能做线性组合，不能做条件判断、取最大值等非线性操作；真实模型需要非线性层。
