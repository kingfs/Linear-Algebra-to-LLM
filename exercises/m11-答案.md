# M11 习题答案

> 对应 [m11-习题](m11-习题.md)。

## A 概念题

1. one-hot $\mathbf{e}_k$ 只有第 $k$ 位为 1；$E^\top\mathbf{e}_k$ 取出 $E$ 的第 $k$ 行，正是查表结果。计算上可直接索引，避免 $V$ 维乘法。
2. $W_2(W_1\mathbf{x})=(W_2W_1)\mathbf{x}$；没有非线性，深度退化为一个线性变换。Transformer 因此在每层间插入 GELU/SiLU 等非线性。
3. 分开投影让「提问」「被查询」「内容」有三种独立表示；共享会迫使匹配与内容耦合，表达力下降，且无法分别学习「我需要什么」与「我能提供什么」。
4. 若 $q,k$ 各分量独立同分布、方差 1，则 $q^\top k$ 方差为 $d_k$，标准差 $\sqrt{d_k}$；不缩放会让 softmax 饱和、梯度消失。除以 $\sqrt{d_k}$ 把方差拉回 1。
5. softmax 后再置零会破坏行和为 1，输出不再是凸组合；在 softmax 前设 $-\infty$，指数为 0，归一化后严格为 0。
6. LayerNorm 减均值再除标准差，RMSNorm 只除均方根；后者少一次均值计算、少一组 $\beta$ 参数，速度更快，适合大模型。
7. 缓存每层每头历史 token 的 K、V；避免重复计算历史，但需按 $2BHTd_k$ 存显存，随序列长度/层数线性增长。
8. 作用在**更新** $\Delta W=BA$ 上；$B=0$ 保证初始 $\Delta W=0$，模型从预训练行为开始，训练稳定。

## B 计算题

1. $50000\times1536=76{,}800{,}000$；fp16 约 $76.8\text{M}\times2=153.6$ MB $\approx146.5$ MiB。
2. $2048\times8192+8192+8192\times2048+2048=33{,}562{,}624$；24 层约 $8.055\times10^8$。
3. $512^2=262{,}144$ 个元素/头；16 头 $4{,}194{,}304$ 个，fp16 约 8 MiB。
4. $e^3=20.09,e^1=2.718,e^0=1$，和 $23.81$，输出 $(0.844,0.114,0.042)$；$T=0.5$ 时输入 $(6,2,0)$，$e^6=403.4,e^2=7.389,1$，和 $411.8$，输出 $(0.980,0.018,0.0024)$。
5. 元素 $2\times32\times4096\times128=33{,}554{,}432$；fp16 字节 $67{,}108{,}864=64$ MiB/层；32 层 2 GiB。
6. $H_{kv}=8$：单层 16 MiB，32 层 512 MiB。
7. $2\times4096\times16=131{,}072$；缩放 $\alpha/r=2$。
8. $s=0.5/127\approx0.003937$；$q=\operatorname{round}(0.1/0.003937)=25$；$\hat{x}=0.09843$，误差约 $0.00157$。

## C 大模型题

1. $12\times4096^2\times32=6.442\times10^9$；embedding $32000\times4096=1.311\times10^8$；总约 $6.57\times10^9$。
2. 无缓存：$\sum_{t=1}^T O(t^2d)=O(T^3d)$；有缓存：prefill $O(T^2d)$ + decode $T\times O(Td)=O(T^2d)$，低一个数量级。
3. Decode 每步只算一个 token，矩阵乘的 $M=1$，时间花在读权重/KV（带宽）；prefill 的 $M=T$ 很大，算力利用率高。Decode 优化：KV 量化、GQA；prefill 优化：FlashAttention、大 batch。
4. 所有专家参数必须可加载（显存按总参数），但每 token 只算 top-k 个专家（计算按激活参数）；部署时需要足够显存装全部专家，但算力需求接近小模型。
5. 可能原因：学习率过大、attention logits 爆炸/softmax 饱和、bf16/fp16 溢出、数据异常 batch、梯度累积错误。指标：梯度范数、logits/激活最大值、loss 分量、学习率、验证 loss。

## D 开放题

1. 没有意义：所有头输出相同，拼接只是重复，$W_O$ 无法创造新信息。检测：头输出的协方差/奇异值、注意力图相似度、消融单个头看性能变化。
2. 任务与预训练分布差异大、需要大量新知识/多语言/长链推理时，低秩可能不够。实验：扫 $r$、比较不同层的秩分配、看验证集随 $r$ 的饱和点。
3. 误差：4-bit 步长更大、舍入误差累积；outlier：少数极大值撑大 $s$，小值精度丢失；校准：校准集不代表性，per-tensor 粒度过粗。可尝试 per-group、AWQ/GPTQ 类方法、保留敏感层高精度。
