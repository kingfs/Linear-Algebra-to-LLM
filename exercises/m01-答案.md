# M01 习题答案

> 对应 [m01-习题](m01-习题.md)。数值保留 3 位小数。

## A 概念题

1. 箭头：三维空间中一个方向；坐标：标准基下的三个系数；数据：某对象的三个特征。用户偏好最适合「数据」身份，因为每一维对应可解释的特征（如节奏、抒情度、电子感）。
2. 点积受长度影响，余弦除以两个范数、只看方向。点积适合长度本身有意义的场景（attention 打分、加权求和）；余弦适合比较语义方向（检索、聚类）。
3. 非零正交向量一定线性无关：若 $\sum c_i\mathbf{v}_i=0$，与 $\mathbf{v}_j$ 做内积得 $c_j\|\mathbf{v}_j\|^2=0$，故 $c_j=0$。反之不成立：线性无关未必正交（如 $(1,0),(1,1)$）。
4. L1 的等高线是菱形，顶点在坐标轴上，最优解容易落在轴上使部分坐标为 0；L2 是圆形，收缩但不产生精确零。
5. 若残差在投影方向有非零分量，沿该方向微调投影点可进一步缩短距离，与「最优」矛盾；不正交说明投影点不是最近点。
6. 组合通常有无穷多个，枚举不完；实际求的是一组基和维数（秩），有限个向量就能描述整个张成。

## B 计算题

1. (a) $3+0-2=1$；(b) $\|\mathbf{u}\|_2=3$，$\|\mathbf{v}\|_1=4$；(c) $\|\mathbf{v}\|_2=\sqrt{10}$，$\cos=1/(3\sqrt{10})\approx0.105$；(d) $\frac{\mathbf{u}^\top\mathbf{v}}{\|\mathbf{v}\|^2}\mathbf{v}=\frac{1}{10}(3,0,-1)=(0.3,0,-0.1)$。
2. $\alpha=(2+6)/5=1.6$，$\mathbf{p}=(1.6,3.2)$，$\mathbf{e}=(0.4,-0.2)$；$\mathbf{e}^\top\mathbf{u}=0.4-0.4=0$；$\|\mathbf{x}\|^2=13$，$\|\mathbf{p}\|^2=12.8$，$\|\mathbf{e}\|^2=0.2$，和 13。
3. $\mathbf{v}_2=2\mathbf{v}_1$，所以三者线性相关；但 $\mathbf{v}_1,\mathbf{v}_3$ 无关，张成 $\mathbb{R}^2$。$(3,5)=3(1,2)-1(0,1)$，可以。
4. $\hat{\mathbf{x}}=(1/3,2/3,2/3)$，$\hat{\mathbf{y}}=(2/\sqrt5,1/\sqrt5,0)$；余弦 $=\frac{4}{3\sqrt5}\approx0.596$；$\mathbf{y}$ 放大 10 倍余弦不变。
5. $\mathbf{a}\times\mathbf{b}=(-2,1,1)$；面积 $\|\mathbf{a}\times\mathbf{b}\|=\sqrt6\approx2.449$。

## C 大模型题

1. 检索关心语义方向，文本长度/词频不应影响，故用余弦；attention 需要保留 key 的「强度/置信度」信息，且除以 $\sqrt{d_k}$ 控制方差，故用未归一化点积。余弦对长度不敏感，attention 对长度敏感。
2. $\mathbf{h}'=\mathbf{h}-\frac{\mathbf{h}^\top\mathbf{d}}{\|\mathbf{d}\|^2}\mathbf{d}$；$\|\mathbf{h}'\|^2=\|\mathbf{h}\|^2-\frac{(\mathbf{h}^\top\mathbf{d})^2}{\|\mathbf{d}\|^2}\le\|\mathbf{h}\|^2$，只会变短。
3. 未缩放标准差 $\sqrt{64}=8$；缩放后 1。未缩放时 softmax 输入波动大，容易饱和、梯度小；缩放后工作在梯度良好区间。
4. 不能；需检查：该模型的余弦基线分布（是否整体偏高）、两段文本是否同领域/同语言、是否只是共享停用词、是否是反义词/模板句。

## D 开放题

1. 逐元素乘会改变尺度、破坏恒等路径，梯度经过连乘容易消失/爆炸；也表示不再是「叠加」，而是「门控」，需要额外的归一化与初始化；深层训练更困难。
2. 随机采样 $N$ 个 embedding，计算两两余弦的均值与分布，与「随机正交向量」的基线（均值 0）比较；也可做 PCA 看第一主成分解释方差比例，比例高说明表示集中在一个锥形区域。
