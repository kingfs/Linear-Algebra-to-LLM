## A 评测的数学：概念题

1. 一个 benchmark 的“五件套”是什么？为什么“同题集、不同 harness”仍然不可比？
2. pass@1、pass@k、pass^k、avg@n 分别回答什么问题？产品选型更该看哪一个？
3. 抽样误差、执行方差、协议方差分别来自哪里？哪一个在 Agent 评测里最大？
4. 为什么“95% 置信区间”不等于“真值有 95% 的概率落在区间内”？对写报告的人，更实用的说法是什么？

## B 评测的数学：计算题

1. 400 题、答对 320 题。求 $\hat p$ 与 95% CI 半宽；若要把半宽压到 ±2 pp，至少需要多少题（按 $p=0.8$ 估）？
2. $n=10,c=3$。求 pass@1、pass@5、pass^5。
3. 两个模型各跑 500 题，A 对 356 题、B 对 349 题。求两者准确率、差值的 95% CI；差距显著吗？
4. 某任务单次成功率 0.5，独立假设下 pass@3 是多少？若实测 pass^3 只有 0.05，说明什么？

## C 知识与推理

1. MMLU、MMLU-Pro、MMLU-Redux 三者的关系是什么？各自解决什么问题？
2. 为什么 2026 年的前沿模型卡不再报 MMLU？举两个理由，并说明“不报”是否等于“不考知识”。
3. GPQA Diamond 只有 198 题。这个规模对“两个模型差 2 分”的结论意味着什么？
4. HLE 的 no-tools 与 with-tools、text-only 子集分别是什么？为什么不能混比？
5. AA-Omniscience 的综合分为什么可能为负？它想奖励什么行为？

## D 代码与软件工程

1. HumanEval、LiveCodeBench、SWE-bench、Terminal-Bench 分别处在“代码能力”的哪一级台阶？
2. SWE-bench、Verified、Pro、Pro V2、DeepSWE 各自补了上一代的什么漏洞？
3. Terminal-Bench 的语义化版本规则是什么？为什么 2.1 与 4.0 不能直接比？
4. 为什么同一模型换 harness 能差 10 分以上？举出至少三个 harness 会改变的因素。
5. NL2Repo-Bench 与 ProgramBench 都在考“从零构建”，它们的输入和判分有什么不同？

## E Agent 与工具

1. BFCL、τ-bench、OSWorld 分别测哪一层？判分方式各是什么？
2. 为什么 τ-bench 的分数要看后端数据库状态，而不是对话文本？
3. MCP-Atlas 的失败诊断里，“认知失败”指什么？为什么它比“工具调用失败”更值得关注？
4. APEX-Agents 1.1 的 scattergunning 是什么？它如何利用 rubric 判分？
5. 为什么企业 Agent 评测要专门测“拒绝不可行任务”？

## F 指令遵循与偏好

1. IFEval、IFBench、IFStruct、Multi-IF 各测什么？为什么 IFBench 更抗“背题型”？
2. 4 个约束的通过率分别为 0.95、0.9、0.85、0.8，假设独立，联合通过率是多少？若实际只有 0.55，说明什么？
3. AlpacaEval 2.0 的“长度控制”解决什么问题？它是否消除了所有 judge 偏差？
4. 为什么 Qwen3.8 的 IFBench 可能高于 Opus，而后者在 GPQA/HLE 上更强？这说明 IFBench 量的是什么？

## G 多模态与长上下文

1. 多模态评测的四层是什么？2026 年的卡片为什么更愿意报 CharXiv/Chartography，而不是 MMMU-Pro？
2. 一张 $2048\times2048$ 的图，按 $14\times14$ patch、$2\times2$ 合并，视觉 token 大约多少？是 $1024\times1024$ 的几倍？
3. “with CI”与“without CI”差 5–20 分。读表时应该怎么处理？
4. claimed context 与 effective context 的区别是什么？RULER 量的是哪一个？
5. 视频评测为什么不能简单当成“多帧图片”？

## H 读表与选型：场景与开放题

1. 老板给你三张卡：LFM3-1.7B、Qwen3.8-27B、DeepSeek-V4.1-Flash-1017。写出你的“读表七问”，并说明哪三项最可能让结论翻车。
2. 你的场景是 24 GB 单卡、离线、128k 文档问答。三个候选里你选谁？写出验证方案与失败判据。
3. 公开榜 A 第一、B 第二；你的 100 题自建集 B 更好。你选谁？需要补哪些证据才能说服老板？
4. 为“代码 Agent 上线”设计一份一页纸评测报告：指标、题量、harness、成本、回滚阈值。
5. 用一句话向非技术同事解释：“为什么排行榜第一名不一定适合我们？”
