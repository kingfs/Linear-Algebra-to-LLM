# M01 习题：向量与几何

> 对应模块：[M01 向量与几何](../01-向量与几何/README.md)
> 先独立完成，再对 [答案](m01-答案.md)。计算题保留中间步骤。

## A 概念题

1. 用箭头、坐标、数据三种身份描述同一个向量 $(0.7,-0.2,0.4)$，并说明哪种身份最适合「用户偏好」场景。
2. 点积和余弦相似度都在衡量「相似」，它们的本质区别是什么？各自适合什么场景？
3. 「正交」与「线性无关」有什么关系？非零正交向量一定线性无关吗？反之呢？
4. L1 与 L2 正则化都会让参数变小，为什么 L1 更容易产生「很多零」？
5. 投影的残差为什么必须与投影方向正交？如果不正交，说明什么？
6. 张成是一个集合。为什么实际计算张成不是把所有组合枚举一遍？「求张成」在计算上到底求什么？

## B 计算题

1. $\mathbf{u}=(1,-2,2)$，$\mathbf{v}=(3,0,-1)$。求：
   (a) $\mathbf{u}^\top\mathbf{v}$；(b) $\|\mathbf{u}\|_2$、$\|\mathbf{v}\|_1$；(c) 夹角余弦；(d) $\mathbf{u}$ 在 $\mathbf{v}$ 方向上的投影向量。
2. $\mathbf{x}=(2,3)$，$\mathbf{u}=(1,2)$。求投影 $\mathbf{p}$、残差 $\mathbf{e}$，验证 $\mathbf{e}^\top\mathbf{u}=0$，并验证勾股定理。
3. 判断 $\mathbf{v}_1=(1,2)$、$\mathbf{v}_2=(2,4)$、$\mathbf{v}_3=(0,1)$ 是否线性无关；$(3,5)$ 能否写成三者的线性组合？
4. 把 $\mathbf{x}=(1,2,2)$ 与 $\mathbf{y}=(2,1,0)$ 归一化，求余弦相似度；若把 $\mathbf{y}$ 放大 10 倍，余弦是否改变？
5. 三维中 $\mathbf{a}=(1,0,2)$，$\mathbf{b}=(0,1,-1)$，求 $\mathbf{a}\times\mathbf{b}$ 及平行四边形面积。

## C 大模型题

1. 一句话解释：为什么文本检索通常用余弦，而 attention 用未归一化点积？各自对「长度」的敏感度如何？
2. 设隐藏状态 $\mathbf{h}\in\mathbb{R}^{4096}$，概念方向 $\mathbf{d}\in\mathbb{R}^{4096}$。写出「从 $\mathbf{h}$ 中移除 $\mathbf{d}$ 方向成分」的公式，并说明结果范数如何变化。
3. 设 $d_k=64$，query/key 各分量独立同分布 $\mathcal{N}(0,1)$。未缩放点积的标准差约为多少？除以 $\sqrt{d_k}$ 后呢？这对 softmax 有什么影响？
4. 两个 4096 维 embedding 的余弦为 0.92。能否直接判断它们语义相同？列出至少两个需要额外检查的因素。

## D 开放题

1. 如果 residual connection 改成 $\mathbf{h}\leftarrow\mathbf{h}\odot\operatorname{sublayer}(\mathbf{h})$（逐元素乘），会对训练和表示产生什么影响？
2. 设计一个实验，验证「embedding 的余弦相似度整体偏高（各向异性）」。你会如何量化？
