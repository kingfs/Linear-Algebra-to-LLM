# M02 习题答案

> 对应 [m02-习题](m02-习题.md)。

## A 概念题

1. 含零、对加法封闭、对数乘封闭。若 $S$ 非空且对数乘封闭，取 $\mathbf{v}\in S$，$0\mathbf{v}=\mathbf{0}\in S$。
2. 两两不共线只排除「两两成比例」；三个向量仍可能共面，例如 $(1,0,1),(0,1,0),(1,1,1)$，第三等于前两之和。
3. 线性无关 + 张成。只无关：描述不了整个空间；只张成：坐标不唯一。
4. $\operatorname{rank}(A)+\dim\operatorname{null}(A)=n$。秩是输出有效维数，零空间是被压成零的输入维数，$n$ 是输入维数。
5. 因为 $A_{\mathcal{B}}=P^{-1}AP$，特征多项式、行列式、迹在相似变换下不变；它们描述线性映射本身，而非某一组基下的矩阵。
6. $S^\perp$ 是与 $S$ 中所有向量正交的向量集合；补集是「不在 $S$ 中」的向量，两者完全不同。零向量属于 $S^\perp$ 但不属于补集。

## B 计算题

1. (a) 是（过原点的平面）；(b) 否（不含零）；(c) 否（两个坐标平面的并，对加法不封闭，如 $(1,0,0)+(0,1,0)=(1,1,0)$）；(d) 是（直线）。
2. $\mathbf{v}_1+\mathbf{v}_2=(3,5,7)=\mathbf{v}_3$，相关；关系 $\mathbf{v}_1+\mathbf{v}_2-\mathbf{v}_3=0$。
3. 行变换：$R_2-2R_1=(0,1,1)$，$R_3-R_1=(0,1,1)$，故秩 2；列空间维数 2；零空间维数 $3-2=1$。
4. $x_1+2x_2=0,\ x_2+x_3=0$；令 $x_3=t$，$x_2=-t$，$x_1=2t$，基 $(2,-1,1)$。
5. 解 $a(1,2)+b(2,3)=(4,7)$：$a+2b=4,\ 2a+3b=7$，得 $a=2,b=1$。
6. $\mathbf{q}_1=(1,1,0)/\sqrt2$；$\mathbf{u}_2=(1,2,0)-\frac{3}{\sqrt2}\mathbf{q}_1=(1,2,0)-(1.5,1.5,0)=(-0.5,0.5,0)$，$\mathbf{q}_2=(-1,1,0)/\sqrt2$；$\mathbf{u}_3=(0,0,1)$，$\mathbf{q}_3=(0,0,1)$。
7. $P^{-1}=\frac12\begin{bmatrix}1&1\\1&-1\end{bmatrix}$；$P^{-1}AP=\begin{bmatrix}3&0\\0&1\end{bmatrix}$；迹 4、行列式 3 不变。

## C 大模型题

1. $\operatorname{rank}(\Delta W)\le16$；参数量 $2\times4096\times16=131{,}072$；全参数 $4096^2=16{,}777{,}216$，压缩约 128 倍。
2. 秩最大 $\min(512,4096)=512$；前 32 个奇异值占 99% 说明有效秩约 32，表示高度集中在一个低维子空间。
3. 不改变；正交变换保内积：$\langle Q\mathbf{x},Q\mathbf{y}\rangle=\mathbf{x}^\top Q^\top Q\mathbf{y}=\mathbf{x}^\top\mathbf{y}$，范数也不变。
4. 若头输出矩阵的列（各头展平）近似线性相关，则其秩小于头数，说明独立信息少于头数；可用头输出的协方差矩阵的秩/奇异值谱检测。

## D 开放题

1. 支持：权重/激活奇异值快速衰减、LoRA 有效、PCA 可解释；反例：生成任务需要高频细节，某些层/输入的有效秩很高，且「低秩」不等于「低维语义」。若为真：压缩 KV Cache、低秩推理、稀疏激活。
2. 可约束 $W'=W+\Delta W$ 的更新满足 $Q^\top Q=I$ 或 $\Delta W$ 与 $W$ 的奇异子空间正交；代价是优化更难（需要在流形上更新）、表达能力受限、可能妨碍任务适配。
