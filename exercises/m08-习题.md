# M08 习题：微积分与优化

> 对应模块：[M08 微积分与优化](../08-微积分与优化/README.md)
> 先独立完成，再对 [答案](m08-答案.md)。计算题请写出中间步骤，不要只写结果。

## A 概念题

1. 偏导数存在是否意味着函数可微？用反例说明。梯度 $\nabla f$ 的形状由什么决定？
2. 方向导数为什么要求方向向量是单位向量？用柯西–施瓦茨不等式证明「梯度方向是上升最快的方向」。
3. 设 $F:\mathbb{R}^4\to\mathbb{R}^2$。$J_F$ 是什么形状？链式法则 $J_{G\circ F}=J_GJ_F$ 中，中间维数为什么会被消掉？反向传播为什么不显式构造 $J_F$？
4. Hessian 在什么条件下对称？「$H$ 正定 ⇒ 严格局部极小」的直觉是什么？为什么半正定时判据会失效？
5. 凸性的一阶判据与二阶判据分别是什么？为什么凸函数上「局部最优 = 全局最优」？大模型的损失通常不凸，这个事实还有用吗？

## B 计算题

1. $f(x,y)=x^2+3y^2$，$\mathbf{x}_0=(1,1)$。
   (a) 求 $\nabla f(\mathbf{x}_0)$；
   (b) 求沿 $\mathbf{u}=(3/5,4/5)^\top$ 的方向导数；
   (c) 求最陡上升方向及其变化率。
2. 对 $f(x,y)=x^2+3y^2$，从 $(1,1)$ 出发，取 $\eta=0.1$ 做两步梯度下降。写出每步的点与函数值，并验证 $\eta<2/\lambda_{\max}$。
3. $F(x,y,z)=(x^2y,\;yz+x)$，在 $(1,2,3)$ 处求 $J_F$，并用它估计 $F(1.1,\,1.9,\,3.2)$。
4. $f(x,y)=2x^2+2xy+y^2$，求 Hessian、特征值，判断原点是极小、极大还是鞍点。
5. $f(x,y)=x^2+2y^2+xy$，从 $(1,1)$ 出发做一步牛顿法。写出梯度、Hessian、线性方程的解与落点。
6. 用拉格朗日乘子求 $\min x^2+y^2+z^2$ s.t. $x+2y+3z=14$，写出最优点、乘子与最优值。

## C 大模型题

1. 线性层 $\mathbf{z}=W\mathbf{x}+\mathbf{b}$，$W=\begin{bmatrix}1&2\\0&1\end{bmatrix}$，$\mathbf{x}=(1,-1)^\top$，$\mathbf{b}=\mathbf{0}$，目标 $\mathbf{y}=(0,1)^\top$，损失 $L=\frac12\|\mathbf{z}-\mathbf{y}\|^2$。求 $\mathbf{z}$、$\partial L/\partial\mathbf{z}$、$\partial L/\partial W$、$\partial L/\partial\mathbf{x}$，并验证每个梯度的形状。
2. 一个 batch 的线性层：$X\in\mathbb{R}^{8\times512}$，$W\in\mathbb{R}^{2048\times512}$，$Z=XW^\top+\mathbf{b}$。写出 $Z$、上游 $\Delta=\partial L/\partial Z$、$\partial L/\partial W$、$\partial L/\partial X$ 的形状。若用 Adam，除参数外还要为 $W$ 存几个同形状张量？
3. 某层损失曲面的 Hessian 最大特征值为 $16$，最小特征值为 $0.04$。学习率的安全上界是多少？条件数是多少？在最优学习率下，慢方向每步收缩多少？把误差降到 $10^{-3}$ 约需多少步？

## D 开放题

1. 大模型损失非凸，为什么「最后一层是凸的」仍然有实用价值？举一个具体场景，并说明它的局限。
2. 如果让你在「完整牛顿法」「Adam」「Hessian–向量乘积 + 共轭梯度」中为 100 亿参数模型选优化方案，你会怎么选？从显存、每步成本、收敛保证三方面论证。
