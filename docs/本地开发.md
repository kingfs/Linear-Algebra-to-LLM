# 本地开发：用 go-task 一条命令跑起来

> 这一页写给本地维护者：不需要记住 `pnpm`、`python3`、`node` 的一长串参数，统一从 `task` 进入。
>
> 任务定义在仓库根目录 [`Taskfile.yml`](https://github.com/kingfs/Linear-Algebra-to-LLM/blob/main/Taskfile.yml)；Web 细节见 [`web/README.md`](../web/README.md)。

## 0. 安装工具

| 工具 | 版本 | 用途 |
| --- | --- | --- |
| [Go Task](https://taskfile.dev/) | v3.40+ | 本页所有命令的入口 |
| Node.js | 24+ | Astro / React 构建 |
| pnpm | 11+ | Web 依赖与脚本 |
| Python | 3.12+ | 内容检查、lab、画图 |
| uv | 0.5+ | 按需创建 Python 环境 |
| Google Chrome | 任意新版 | `task e2e` 浏览器检查 |

macOS 安装 Task：

```bash
brew install go-task/tap/go-task
# 或
go install github.com/go-task/task/v3/cmd/task@latest
```

检查：

```bash
task doctor
```

## 1. 第一次启动

```bash
task setup     # 安装 web 依赖 + 创建 .venv + 安装 Python 依赖
task dev       # 启动 Astro，默认 http://127.0.0.1:4321/
```

`task dev` 等价于：

```bash
cd web && pnpm dev --port 4321
```

## 2. 常用任务

| 命令 | 作用 |
| --- | --- |
| `task` / `task --list` | 列出全部任务 |
| `task doctor` | 检查 python/node/pnpm/uv/task/Chrome |
| `task setup` | 安装 Web 与 Python 依赖 |
| `task dev` | 启动开发服务器（别名 `serve`、`start`） |
| `task sync` | 只同步 Markdown 到 Web 内容集合 |
| `task build` | 构建静态站点到 `web/dist` |
| `task preview` | 预览构建产物 |
| `task check` | 内容三件套：结构 / 文献 / 链接 |
| `task check:content` | `scripts/check.py` |
| `task check:refs` | `scripts/check_refs.py` |
| `task check:links` | `scripts/check_links.py` |
| `task check:quiz MODULE=m01` | 校验单个题库 |
| `task check:quiz:all` | 校验全部题库 |
| `task check:web` | 先构建，再查站内链接 / 锚点 / 渲染 |
| `task check:all` | 内容 + Web 全检 |
| `task e2e` | 临时起 dev server，跑 13 项浏览器检查 |
| `task lab LAB=01` | 跑一个 NumPy 实验 |
| `task labs` | 跑全部实验（较慢） |
| `task figures` | 重新生成全部 SVG 图 |
| `task build:pages` | 按 `/Linear-Algebra-to-LLM/` 子路径构建 |
| `task clean` | 清理 `web/dist`、生成目录与 `__pycache__` |
| `task status` | 看工作区状态与最近提交 |
| `task ci` | 本地 CI：内容 + 构建 + 站点检查 |

## 3. 变量

| 变量 | 默认 | 示例 |
| --- | --- | --- |
| `PORT` | `4321` | `task dev PORT=4400` |
| `BASE_PATH` | `/` | `task build BASE_PATH=/Linear-Algebra-to-LLM/` |
| `MODULE` | `m01` | `task check:quiz MODULE=m13` |
| `LAB` | `01` | `task lab LAB=07` |
| `PYTHON` | `python3` | `task check:content PYTHON=.venv/bin/python` |

## 4. 三种工作流

### 改内容（Markdown / 题库 / 图）

```bash
task check          # 结构、文献、链接
task dev            # 浏览器里看效果
task check:web      # 构建后查站内链接与渲染
```

### 改 Web（Astro / React / 样式）

```bash
task check:web
task e2e
```

### 发布前

```bash
task ci             # check + check:web
task build:pages    # 子路径构建；产物在 web/dist
```

## 5. 常见问题

**`task: command not found`**  
按 §0 安装 Go Task，确认 `~/.local/bin` 或 Homebrew 的 bin 在 `PATH` 里。

**`pnpm install` 很慢 / 失败**  
先确认 Node 24 与 pnpm 11；公司网络可配置 `pnpm config set registry <镜像>`。`task setup` 只装 Web 依赖和 Python 依赖，不会改全局环境。

**`task e2e` 找不到 Chrome**  
脚本默认使用 `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`。其他系统或路径：

```bash
CHROME_PATH=/path/to/chrome task e2e
```

**端口被占用**  
换端口：

```bash
task dev PORT=4400
task e2e PORT=4400
```

**图没有更新**  
`task figures` 会重新跑 `figures/scripts/fig_*.py`；产物在 `figures/out/`，映射在 `figures/manifest.yaml`。不要手改 `web/public/figures/`。

**构建后页面是旧内容**  
`task build` 会先 `sync`；如果仍不对，`task clean && task build`。

## 6. 不要手改的目录

这些是生成物，已在 `.gitignore`：

- `web/src/content/generated/`
- `web/src/data/`
- `web/public/figures/`
- `web/public/labs/`
- `web/public/search.json`
- `web/dist/`
- `web/.astro/`

改正文请改根目录 Markdown；改图请改 `figures/scripts/`；改完再 `task sync` 或 `task build`。

## 7. 与 AGENTS.md 的关系

[`AGENTS.md`](../AGENTS.md) 仍是写作、检查、提交的权威规范。`task` 只是把其中常用命令包了一层：

- 内容门禁：`task check` = `check.py` + `check_refs.py` + `check_links.py`
- Web 门禁：`task check:web` = `pnpm build` + `check-site-links.mjs` + `check-render.mjs`
- 浏览器门禁：`task e2e` = `scripts/e2e.mjs`

提交前至少跑 `task check`；改 Web 再跑 `task check:web` 与 `task e2e`。
