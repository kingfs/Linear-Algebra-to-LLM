# 0.3 标量、向量、矩阵、张量：按轴理解形状

> **本节位置**：模块 0 · 准备 ｜ **前置**：[0.2](02-数学语言-集合映射与求和.md) ｜ **预计**：30 分钟
>
> **一句话**：张量就是「用多个下标索引的数组」；形状是每个下标能取多少个值。

## 0. 场景引入

你兴冲冲跑一段 attention 代码，报错：

```text
RuntimeError: mat1 and mat2 shapes cannot be multiplied (2x5x8 and 8x24)
```

你盯着 `[2, 5, 8]` 想：这不就是三个数吗？为什么不能乘？

答案是：**矩阵乘法只作用在最后两个轴上**。`[2,5,8] @ [8,24]` 实际是「两个 batch，每个 `[5,8]` 的矩阵，去乘 `[8,24]`」，结果应为 `[2,5,24]`。报错说明你心里的轴和代码的轴对不上。

这一节只做一件事：**让你看到任何一个形状，都能立刻说出每个轴代表什么。**

## 1. 直觉

先玩一个「数轴」游戏。一个数组有几个轴？看它需要几个下标才能定位一个数：

| 对象 | 例子 | 需要几个下标 | 形状 |
|---|---|---|---|
| 标量 | $3.14$ | 0 个 | `[]` |
| 向量 | $(0.2,-0.5,1.0)$ | 1 个：`x[i]` | `[3]` |
| 矩阵 | $\begin{bmatrix}1&2\\3&4\end{bmatrix}$ | 2 个：`A[i,j]` | `[2,2]` |
| 三维张量 | 一批矩阵 | 3 个：`T[i,j,k]` | `[2,2,2]` |

> 💡 **一句话直觉**：**轴 = 一种「分类维度」；形状 = 每种分类各有几项。**

比如一批句子：`[B, T, D]`。
- 轴 0（`B`）：第几个句子；
- 轴 1（`T`）：句子里第几个 token；
- 轴 2（`D`）：这个 token 的向量有多少维。

`x[2, 7, 100]` 就是「第 3 个句子的第 8 个 token 的第 101 个特征」。

## 2. 定义

### 2.1 张量

一个 $k$ 阶张量（rank-$k$ tensor，这里的 rank 指**轴的个数**，不是矩阵的秩）是

$$
\mathcal{T}\in\mathbb{R}^{n_1\times n_2\times\cdots\times n_k}
$$

它的形状（shape）是元组 $(n_1,\dots,n_k)$，元素个数是 $\prod_{i=1}^k n_i$。

- $k=0$：标量；
- $k=1$：向量；
- $k=2$：矩阵；
- $k\ge3$：高阶张量。

张量分析（tensor calculus）的成套规则——协变指标、缩并与协变导数——由[里奇与列维-奇维塔](#ref-ricci-1900)在 1900 年系统化。那时它服务于微分几何与广义相对论；今天深度学习借用的只是「多下标数组 + 每个轴独立索引」这一层，不涉及坐标变换。

> ⚠️ 注意：PyTorch 里 `tensor.dim()` 返回轴的个数；线性代数里 $\operatorname{rank}(A)$ 是矩阵的秩。两个「rank」不是一回事（第 2.6 节）。

### 2.2 索引、切片、轴

- **索引**：`x[i]` 取第 $i$ 个元素（代码从 0 开始）。
- **切片**：`x[:, 0, :]` 固定第 1 轴为 0，保留其余轴。
- **轴（axis）**：运算沿哪个方向进行。`sum(axis=1)` 表示「把轴 1 压掉」。
- **转置 / 换轴（permute）**：重排轴的顺序，元素不变。

### 2.3 变形（reshape）

`reshape` 把形状从 $(n_1,\dots,n_k)$ 改成 $(m_1,\dots,m_l)$，只要元素总数不变：

$$
\prod n_i=\prod m_j
$$

它**不改变内存中的元素顺序**，只是换一种「怎么索引」的解释。因此 reshape 之后，哪个元素落到哪个位置，完全由「行优先展开」决定。

### 2.4 广播（broadcasting）

两个形状做逐元素运算时，NumPy/PyTorch 从**最右边的轴**开始对齐：

1. 维度相等 → 可以；
2. 其中一个为 1 → 把 1 拉伸成对方长度；
3. 缺失的轴 → 在左边补 1；
4. 否则报错。

例：`[B,T,D] + [D]` → `[B,T,D]`，因为 `[D]` 被看作 `[1,1,D]` 后沿前两个轴复制。

这套「从最右轴对齐」的规则不是框架的随意选择：[Harris 等](#ref-harris-2020)（2020）描述的 NumPy 数组模型给出了 axis、reshape 与 broadcasting 的正式语义，PyTorch 基本沿用。

## 3. 为什么这样定义

如果每个样本都单独存成矩阵，代码里就要写循环：

```python
for b in range(B):
    for t in range(T):
        h[b][t] = W @ x[b][t] + bias
```

GPU 最讨厌这种小循环。把 batch 和序列塞进额外两个轴，一次 `matmul` 就能并行算完 $B\times T$ 个向量。**多出来的轴不是为了数学，而是为了并行**。

同样，多头注意力把 $D$ 拆成 $H\times d_k$，用轴表示「第几个头」，就能让所有头同时计算。轴是**并行维度的载体**。

## 4. 性质与推导

### 4.1 元素总数守恒

$$
\#\text{elements}=\prod_{i=1}^{k}n_i
$$

`reshape` 前后必须相等。例：`[2,3,4]` 有 24 个元素，可以 reshape 成 `[6,4]`、`[2,12]`、`[24]`，但不能变成 `[5,5]`。

### 4.2 批量矩阵乘法

对 `A: [B, m, n]` 与 `B_mat: [n, p]`，`A @ B_mat` 的结果是 `[B, m, p]`，定义为对每个 $b$：

$$
C[b]=A[b]\,B_{\text{mat}}
$$

即**矩阵乘法只作用在最后两维**，前面的轴是「批量」。这就是深度学习框架的默认语义。

### 4.3 拆头与合头

设 `X: [B, T, D]`，$H$ 个头，$d_k=D/H$。

```text
X.reshape(B, T, H, d_k)      # [B, T, H, d_k]
 .transpose(1, 2)            # [B, H, T, d_k]
```

拆头不是数学变换，只是**把隐藏维度 $D$ 重新解释为 $H$ 个长度为 $d_k$ 的子空间**；换轴是为了让 `matmul` 在最后两维（$T$ 与 $d_k$）上计算注意力。这套「拆头 → 打分 → 合头」的流程来自多头注意力（[Vaswani 等](#ref-vaswani-2017), 2017），`[B, H, T, d_k]` 也就成了事实上的标准形状。

### 4.4 广播的形状推导

`[B, H, T, d_k] * [T, T]`：
- 右对齐：`d_k` vs `T` → 不等且都不为 1 → 报错；
- 正确写法是 `[B,H,T,T] @ [B,H,T,d_k]`，或先把 mask 扩成 `[1,1,T,T]`。

## 5. 例子

### 5.1 手算：形状与索引

设 `X` 形状 `[2, 3, 4]`（B=2, T=3, D=4）。

- `X[1, 2, 3]`：第 2 个样本、第 3 个 token、第 4 维；
- `X[:, 0, :]`：所有样本的第 1 个 token，形状 `[2, 4]`；
- `X.sum(axis=1)`：对 token 求和，形状 `[2, 4]`；
- `X.transpose(0, 2, 1)`：形状 `[2, 4, 3]`；
- `X.reshape(2, 12)`：形状 `[2, 12]`，元素顺序不变。

### 5.2 场景：一次多头注意力的形状旅程

| 步骤 | 操作 | 形状 |
|---|---|---|
| 输入隐藏状态 | — | `[B, T, D]` |
| 线性投影 | `X @ Wq` | `[B, T, D]` |
| 拆头 | reshape + transpose | `[B, H, T, d_k]` |
| 打分 | `Q @ K.transpose(-2,-1)` | `[B, H, T, T]` |
| 缩放 + mask + softmax | 逐元素 / 沿最后轴 | `[B, H, T, T]` |
| 加权 value | `P @ V` | `[B, H, T, d_k]` |
| 合头 | transpose + reshape | `[B, T, D]` |
| 输出投影 | `@ Wo` | `[B, T, D]` |

**验算元素数**：`[B,H,T,d_k]` 与 `[B,T,D]` 的元素数相同，因为 $H\cdot d_k=D$。合头之所以能成功，靠的就是这个守恒。

### 5.3 场景：KV Cache 的形状

推理时缓存历史 key/value：`[B, H, T_cache, d_k]`。每生成一个新 token，只追加一列（沿 $T$ 轴），不必重算历史。显存占用约为

$$
2\times B\times H\times T\times d_k\times \text{bytes per element}
$$

系数 2 是 K 和 V 各一份。这个公式在第 11.7 节会展开。

## 6. 常见误区

1. **误区**：张量的「阶」和矩阵的「秩」是一回事。
   **纠正**：阶（rank/ndim）是轴的个数；矩阵的秩是列空间的维数（第 2.6 节）。一个 `[2,3]` 矩阵阶为 2，秩可能是 1。

2. **误区**：`reshape` 会重排元素。
   **纠正**：`reshape` 只改解释方式，不移动数据；`transpose`/`permute` 才改变轴的顺序。两者组合使用时，顺序很容易错，务必用形状和小例子验证。

3. **误区**：广播是「自动对齐所有维度」。
   **纠正**：广播从最右轴对齐，且只有「相等」或「其中一个为 1」才合法。`[B,T,D] + [B,D]` 会失败，因为右对齐后 `T` 对 `B` 不匹配。

4. **误区**：batch 轴也是「特征」。
   **纠正**：batch 轴只是并行打包，不参与特征语义；对 batch 求和/平均是统计操作，不是模型的一部分。

## 8. 通往大模型：把 `[B,T,D]` 刻进脑子

大模型里 90% 的形状都是这四个字母的变体：

- `[B, T, D]`：隐藏状态、embedding 输出、FFN 中间（`4D`）；
- `[B, H, T, d_k]`：每个头的 Q/K/V；
- `[B, H, T, T]`：注意力权重（显存杀手，随 $T^2$ 增长）；
- `[V, D]`：embedding 表，$V$ 是词表大小；
- `[D, 4D]`、`[4D, D]`：FFN 的两个权重；
- `[D, r]`、`[r, D]`：LoRA 的低秩矩阵，$r\ll D$。

**可检验结论**：对 $B=1,T=4096,D=4096,H=32$，注意力矩阵 `[1,32,4096,4096]` 用 fp16 存储需要

$$
32\times4096^2\times2\ \text{bytes}=1\ \text{GiB}
$$

**单层、单头矩阵就要 1 GiB**，这就是长上下文必须先解决注意力复杂度或做分块的原因：[FlashAttention](#ref-dao-2022) 用分块与在线 softmax，始终不把完整矩阵写进显存。

```python
import numpy as np
B, T, D, H = 1, 4096, 4096, 32
d_k = D // H
print("attention 矩阵元素数:", B * H * T * T)
print("fp16 显存 GiB:", B * H * T * T * 2 / 1024**3)
# 1.0 GiB
```

## 9. 练习

1. **概念**：`[2, 3, 4]` 与 `[6, 4]` 的元素数相同，它们能互相 reshape 吗？`[4, 6]` 呢？
2. **计算**：`A: [8, 5, 3]`，`B: [3, 7]`，`A @ B` 的形状是什么？如果改成 `A: [8, 5, 3]`，`B: [8, 3, 7]` 呢？
3. **场景**：解释 `[B, T, D]` 经过 `reshape(B, T, H, D//H).transpose(1, 2)` 后，为什么元素总数不变，以及每个轴现在代表什么。
4. **开放**：为什么框架不把 batch 轴放在最后，而是放在最前？提示：考虑内存布局与广播。

<details>
<summary>参考答案</summary>

1. `[2,3,4] ↔ [6,4]` 可以（24 个元素）；`[4,6]` 也可以 reshape，但元素顺序不同，语义会变，需谨慎。
2. `[8,5,3] @ [3,7]` → `[8,5,7]`；`[8,5,3] @ [8,3,7]` 是批量矩阵乘，→ `[8,5,7]`（逐 batch）。
3. 元素数 $B\cdot T\cdot H\cdot(D/H)=B\cdot T\cdot D$ 不变；轴变为 `[batch, head, token, 每头维度]`。
4. 最左轴是「最外层循环」，与行优先内存布局一致；广播也从右对齐，把 batch 放最左最不容易误伤特征轴。

</details>

## 10. 一页速记

- 阶 = 轴的个数；形状 = 每个轴的长度；元素数 = 各轴长度之积。
- 索引定位元素，切片保留部分轴，`sum(axis=k)` 压掉第 $k$ 轴。
- `reshape` 只改解释，`transpose/permute` 改轴顺序；两者别混。
- 批量矩阵乘只作用在最后两维；广播从最右轴对齐。
- 大模型四件套：`[B,T,D]`、`[B,H,T,d_k]`、`[B,H,T,T]`、`[V,D]`。
