# 公式速查

> 按主题分组；每条给出「什么时候用」。符号约定见 [符号表](../docs/符号表.md)。

## 1. 向量与几何

| 公式 | 用途 |
|---|---|
| $\mathbf{x}\cdot\mathbf{y}=\sum_i x_iy_i=\|\mathbf{x}\|\|\mathbf{y}\|\cos\theta$ | 相似度、夹角 |
| $\|\mathbf{x}\|_2=\sqrt{\sum_i x_i^2}$ | 欧氏长度 |
| $\cos\theta=\dfrac{\mathbf{x}\cdot\mathbf{y}}{\|\mathbf{x}\|\|\mathbf{y}\|}$ | 余弦相似度 |
| $\operatorname{proj}_{\mathbf{u}}\mathbf{x}=\dfrac{\mathbf{x}\cdot\mathbf{u}}{\mathbf{u}\cdot\mathbf{u}}\mathbf{u}$ | 投影到直线 |
| $\|\mathbf{x}+\mathbf{y}\|^2=\|\mathbf{x}\|^2+\|\mathbf{y}\|^2+2\mathbf{x}\cdot\mathbf{y}$ | 勾股/余弦定理 |
| $\mathbf{x}\perp\mathbf{y}\iff\mathbf{x}\cdot\mathbf{y}=0$ | 正交判定 |

## 2. 空间、基与秩

| 公式 | 用途 |
|---|---|
| $\operatorname{rank}(A)+\dim\operatorname{null}(A)=n$ | 秩-零化度 |
| $\dim S+\dim S^\perp=\dim V$ | 正交补 |
| $\mathbf{v}=B[\mathbf{v}]_{\mathcal{B}}$，$[\mathbf{v}]_{\mathcal{B}}=B^{-1}\mathbf{v}$ | 坐标 |
| $A_{\mathcal{B}}=P^{-1}A_{\mathcal{C}}P$ | 相似变换 |
| $\operatorname{rank}(AB)\le\min(\operatorname{rank}A,\operatorname{rank}B)$ | 乘积秩 |
| $\operatorname{rank}(A)=\#\{\sigma_i>0\}$ | 奇异值判秩 |

## 3. 矩阵与方程

| 公式 | 用途 |
|---|---|
| $(AB)^\top=B^\top A^\top$ | 转置 |
| $(AB)^{-1}=B^{-1}A^{-1}$ | 逆 |
| $A\mathbf{x}=\mathbf{b}$ 有解 $\iff\mathbf{b}\in\operatorname{col}(A)$ | 可解性 |
| $A^\top A\hat{\mathbf{x}}=A^\top\mathbf{b}$ | 正规方程 |
| $P=QQ^\top$ | 正交投影矩阵 |
| $A^{+}=V\Sigma^{+}U^\top$ | 伪逆 |
| $\kappa(A)=\|A\|\|A^{-1}\|=\sigma_{\max}/\sigma_{\min}$ | 条件数 |
| $\dfrac{\|\delta\mathbf{x}\|}{\|\mathbf{x}\|}\le\kappa(A)\dfrac{\|\delta\mathbf{b}\|}{\|\mathbf{b}\|}$ | 误差放大 |

## 4. 行列式

| 公式 | 用途 |
|---|---|
| $\det(AB)=\det A\det B$ | 乘法 |
| $\det(A^{-1})=1/\det A$ | 逆 |
| $A$ 可逆 $\iff\det A\neq0$ | 可逆判定 |
| $\det\begin{bmatrix}a&b\\c&d\end{bmatrix}=ad-bc$ | 2×2 |
| $\lvert\det J\rvert$ = 体积伸缩因子 | 换元/Jacobian |

## 5. 特征值与二次型

| 公式 | 用途 |
|---|---|
| $A\mathbf{v}=\lambda\mathbf{v}$ | 特征方程 |
| $\det(A-\lambda I)=0$ | 特征多项式 |
| $\operatorname{tr}A=\sum_i\lambda_i$，$\det A=\prod_i\lambda_i$ | 迹/行列式 |
| $A=PDP^{-1}$ | 对角化 |
| $A=Q\Lambda Q^\top$（对称） | 谱定理 |
| $\mathbf{x}^\top A\mathbf{x}>0\ (\forall\mathbf{x}\neq0)$ | 正定 |
| 正定 $\iff$ 所有特征值 $>0$ $\iff$ 顺序主子式 $>0$ | 判定 |

## 6. SVD 与低秩

| 公式 | 用途 |
|---|---|
| $A=U\Sigma V^\top$ | SVD |
| $A_k=\sum_{i=1}^k\sigma_i\mathbf{u}_i\mathbf{v}_i^\top$ | 截断 SVD |
| $\|A-A_k\|_F^2=\sum_{i>k}\sigma_i^2$ | Eckart–Young |
| $\|A-A_k\|_2=\sigma_{k+1}$ | 谱误差 |
| $\operatorname{rank}(A_k)\le k$ | 低秩 |
| $\sigma_i=\sqrt{\lambda_i(A^\top A)}$ | 奇异值与特征值 |

## 7. 微积分与优化

| 公式 | 用途 |
|---|---|
| $\nabla f=(\partial f/\partial x_1,\dots)^\top$ | 梯度 |
| $D_{\mathbf{u}}f=\nabla f^\top\mathbf{u}$ | 方向导数 |
| $f(\mathbf{x}+\Delta)\approx f(\mathbf{x})+\nabla f^\top\Delta+\frac12\Delta^\top H\Delta$ | 二阶近似 |
| $\partial(A\mathbf{x})/\partial\mathbf{x}=A$ | 矩阵求导 |
| $\partial(\mathbf{x}^\top A\mathbf{x})/\partial\mathbf{x}=(A+A^\top)\mathbf{x}$ | 二次型梯度 |
| $\mathbf{x}_{t+1}=\mathbf{x}_t-\eta\nabla f(\mathbf{x}_t)$ | 梯度下降 |
| 凸：$f(\lambda\mathbf{x}+(1-\lambda)\mathbf{y})\le\lambda f(\mathbf{x})+(1-\lambda)f(\mathbf{y})$ | 凸性 |

## 8. 概率

| 公式 | 用途 |
|---|---|
| $E[X]=\sum_x xp(x)$ | 期望 |
| $\operatorname{Var}(X)=E[X^2]-E[X]^2$ | 方差 |
| $\operatorname{Cov}(X,Y)=E[XY]-E[X]E[Y]$ | 协方差 |
| $\Sigma=E[(\mathbf{x}-\mu)(\mathbf{x}-\mu)^\top]$ | 协方差矩阵 |
| $\mathcal{N}(\mathbf{x};\mu,\Sigma)\propto\exp\left(-\frac12(\mathbf{x}-\mu)^\top\Sigma^{-1}(\mathbf{x}-\mu)\right)$ | 多元高斯 |
| $\pi P=\pi$ | 马尔可夫稳态 |

## 9. 数值与大模型

| 公式 | 用途 |
|---|---|
| $\operatorname{softmax}(\mathbf{z})_i=e^{z_i}/\sum_j e^{z_j}$ | 归一化 |
| $\operatorname{softmax}(\mathbf{z}/T)$ | 温度 |
| $A=\operatorname{softmax}(QK^\top/\sqrt{d_k})$ | attention |
| $\operatorname{LN}(\mathbf{x})=\gamma\odot\frac{\mathbf{x}-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta$ | LayerNorm |
| $\operatorname{RMSNorm}(\mathbf{x})=\gamma\odot\frac{\mathbf{x}}{\sqrt{\operatorname{mean}(x^2)+\epsilon}}$ | RMSNorm |
| KV Cache $=2BHTd_k\cdot\text{bytes}\cdot L$ | 显存 |
| $\Delta W=BA$，参数 $2Dr$ | LoRA |
| $q=\operatorname{round}(x/s)+z$ | 量化 |
| $W'=W_0+\frac{\alpha}{r}BA$ | LoRA 合并 |
| $\|A\|_2=\sigma_{\max}$ | 谱范数 |

## 10. 常用近似与量级

- 参数量：attention $4D^2L$，FFN $8D^2L$；总计约 $12D^2L$。
- 前向 FLOPs/token：约 $2\times$参数量。
- KV Cache：$T$ 翻倍，显存翻倍；GQA 按 $H_{kv}/H$ 缩。
- 高斯矩阵谱范数：$\approx\sigma(\sqrt m+\sqrt n)$。
- fp16 机器精度：$\approx9.77\times10^{-4}$；fp32：$\approx1.19\times10^{-7}$。
